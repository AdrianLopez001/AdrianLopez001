### 📌 Projetos em Destaque

- 🧠 **[Corporate RAG Engine](https://github.com/AdrianLopez001/Corporate-RAG-Engine):** Sistema de busca inteligente que permite consultar documentos corporativos em PDF e Word e obter respostas baseadas nas informações desses arquivos. O sistema utiliza inteligência artificial para interpretar perguntas, localizar conteúdos relevantes e gerar respostas contextualizadas. Conta com back-end em Java e Spring Boot, integração com modelos de IA, banco de dados PostgreSQL com busca vetorial, interface em React, testes automatizados e execução com Docker.  
  `Java 21 • Spring Boot • Spring AI • React • PostgreSQL • pgvector • Docker • GitHub Actions`

- ⚡ **[CareSync](https://github.com/AdrianLopez001/CareSync):** Sistema de agendamento na área da saúde, dividido em serviços independentes para gerenciar consultas e enviar notificações por e-mail. Os serviços se comunicam por meio de mensagens automáticas, permitindo que cada parte funcione de forma independente. O projeto utiliza banco de dados PostgreSQL, testes automatizados e Docker para facilitar a execução e a organização da aplicação.  
  `Java 21 • Spring Boot • RabbitMQ • PostgreSQL • Docker • GitHub Actions`

- ⚽ **[MatchMind AI](https://github.com/AdrianLopez001/Now-or-Never):** Plataforma de análise de futebol que utiliza dados de partidas e modelos de inteligência artificial para estimar resultados e gerar análises estatísticas. O sistema combina três modelos de aprendizado de máquina, realiza simulações de cenários e apresenta informações que ajudam a compreender os fatores que influenciam as previsões. A aplicação conta com uma API desenvolvida em Java e Spring Boot, processamento de dados em Python e um painel visual para apresentar os resultados.  
  `Java • Spring Boot • Python • scikit-learn • SHAP • Next.js • APIs externas`

- 🚗 **[LocParts — Prova de Conceito (PoC)](https://github.com/AdrianLopez001/LocParts):** Prova de conceito para facilitar a identificação de peças automotivas e a criação de orçamentos. A aplicação permite relacionar a placa de um veículo às peças solicitadas e interpretar descrições em texto para encontrar itens correspondentes. O projeto utiliza dados simulados e um agente de IA para demonstrar o funcionamento da solução, com API em Java e Spring Boot, interface em React e armazenamento em PostgreSQL.  
  `Java 17 • Spring Boot 3 • React • PostgreSQL • Docker`
